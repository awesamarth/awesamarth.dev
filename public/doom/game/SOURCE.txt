DOOM engine used by the idkfa easter egg on awesamarth.dev
==========================================================

doom.js and doom.wasm are a WebAssembly build of Chocolate Doom, from Cloudflare's port:

  https://github.com/cloudflare/doom-wasm  (commit 65e0d3a, GPL-2.0, see COPYING.md there)

Built with Emscripten 3.1.64 (autoconf 2.69, automake 1.17):

  autoreconf -fi
  ac_cv_exeext=".html" emconfigure ./configure --host=none-none-none
  emmake make
  wasm-opt websockets-doom.wasm --strip-debug --strip-dwarf -O3 --all-features -o doom.wasm

Changes against that commit (full diff below):
  - configure.ac: build flags updated for current Emscripten, no debug/safe-heap instrumentation
  - opl/opl.c: skip OPL chip detection on Emscripten (it deadlocks waiting for the audio callback),
    which makes the OPL music emulation work in the browser
  - src/doomtype.h: keep `boolean` int-sized when <stdbool.h> is already included (newer
    Emscripten headers include it, which mixed 1- and 4-byte booleans between files)

DOOM1.WAD is the unmodified DOOM shareware v1.9 data file by id Software
(SHA-256 1d7d43be501e67d927e415e0b8f3e29c3bf33075e859721816f652a526cac771).
